---
title: "Troubleshooting"
description: "What to do when something doesn't seem right"
---

Most of the time, an unhelpful-feeling answer is Magnus correctly telling you it doesn't know something — see [Understanding Answers](/help/understanding-answers) before assuming something's broken. This page is about when something has actually gone wrong.

## Magnus took a long time and then failed

Longer, more involved requests (see [Getting Things Done](/collaboration/getting-things-done)) can take a while, but every request has a limit — if something runs too long without finishing, Magnus will stop and let you know rather than hang indefinitely. If this happens:

- Try breaking the request into smaller pieces.
- Try again — a one-off slowdown elsewhere in the system is the most common cause.

## Magnus declined to help with something

If Magnus tells you it's not able to help with a particular request — rather than that it couldn't find an answer — that's usually a deliberate policy boundary rather than a limitation you can work around by rephrasing. If you believe that's a mistake, that's worth raising with your organization's admin team rather than retrying repeatedly.

## Magnus gave an error instead of an answer

Occasionally something in the underlying systems Magnus depends on has a hiccup. If you see an explicit error rather than a normal answer or a "couldn't find that" response:

1. Try the same request again — many issues are momentary.
2. Try rephrasing, in case the specific wording was the trigger.
3. If it keeps happening, contact your organization's support channel with what you asked and roughly when — that detail helps whoever's investigating.

## A file or link looked wrong

See [Getting Things Done](/collaboration/getting-things-done#getting-a-file-back) — only trust a file that actually appears as a real attachment in the conversation. A described-but-missing link is a sign to ask Magnus to try again rather than to click it.

## Magnus seems to have forgotten something

See [What Magnus Remembers](/collaboration/memory) — not everything you've ever said is carried forward, only a curated set of durable facts. Mentioning it again is usually the simplest fix.

## Still stuck?

Reach out to your organization's support channel. Include what you asked, roughly when, and what you expected versus what happened — that's the fastest path to a fix.
