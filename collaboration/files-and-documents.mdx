## Sharing a file with Magnus

You can attach a file to a conversation and ask Magnus about it — a receipt, an invoice, a screenshot, a document you want summarized or checked. Magnus reads what you send and uses it to answer your question or complete your task.

<Note>
  Magnus reads files to help with everyday, in-scope requests — not as a substitute for professional advice. It can read a receipt to help with an expense question, for instance, but it isn't a source of legal, medical, or financial advice just because you attached a relevant document.
</Note>

## Getting files back

When Magnus produces something for you — a report, a summary document, a generated file — it comes back to you as a real attachment in the conversation, not just a description of what it made. See [Getting Things Done](/collaboration/getting-things-done#getting-a-file-back) for what a trustworthy delivered file looks like versus a sign that something went wrong.

## A note on sensitive files

Treat files the way you would with any colleague: don't share anything you wouldn't be comfortable having read by whoever has access to that conversation. See [Privacy & Data](/help/privacy-and-data) for how your organization's data is handled more broadly.
